# Review log

Owner: Legal and IP Compliance. The running record of every originality and name review. New entries go at the bottom of the table and the detail list. These are screening checks, not a clearance, and not legal advice.

First entries: 2026-09-28, P0 wave 1 (placeholder names, move names and the repo name).

## How to read it

**Rating**
- **Low**: no franchise echo found and no conflict that would block us. Proceed.
- **Medium**: an association, or a collision, that needs a decision or a fix before it goes public. Fine as a private working name.
- **High**: echoes a protected franchise term, or the name is too crowded or conflicted to use publicly. Do not use it publicly.

**Decision:** GO, GO (working name only), RENAME BEFORE PUBLIC, or NO-GO.
**Status:** Open (a flag that blocks a phase gate) or Closed.

**Method.** Web searches (a US-only search tool), plus direct checks on 2026-09-28 of the Steam store search, the App Store search API, GitHub, a domain registry record, and the USPTO trademark search run in a browser. A web search is not a trademark clearance. It cannot see other countries' registers or unregistered use, and it can miss things. See "Limits" at the end.

## Detail

### RL-001 Meridian (game title, placeholder)
- **Searched:** web search for games called Meridian; Steam store search for "meridian" (games).
- **Found:** Steam returns 127 results, including three titles named Meridian. Others include Meridian 59 (a 1996 online RPG, still running), Meridian: New World, Meridian: Squad 22, Meridian: Age of Invention, Meridian Strike, a choice-driven cyberpunk RPG called Meridian, and The Meridian (release date 10 July 2026). The word also names a comics character and places in Borderlands 3. No link to Dragon Ball found.
- **Rating:** High as a public title (crowded, hard to find, hard to protect). Low as a private working title.
- **Recommendation:** Keep it as the working title while the repo is private. Never use it in store pages, logos, domains or the repo name. Narrative's replacement supersedes it. Inside the fiction, "meridian" as a line on the globe is fine.

### RL-002 KAI (hero name, placeholder)
- **Searched:** Dragon Ball wiki and Wikipedia pages for Kai and Kaio; web search for other characters called Kai; Steam store search; USPTO trademark search.
- **Found:** In Dragon Ball, Kai is the title element of the franchise's gods (King Kai, Supreme Kai and others), and Dragon Ball Z Kai is an official re-edit of the anime. Kai is also a main hero of LEGO Ninjago. Steam returns 166 results for "kai", including a 2026 game titled KAI. USPTO returns 1,469 records containing KAI, including live filings in class 9 (software), such as LIL KAI (virtual-goods software, pending) and KAI | NETKONNECTOR (AI software, registered).
- **Rating:** High.
- **Recommendation:** NO-GO as a shipped name. Replace it before Art, Audio or Narrative build anything on it. A short hero name that reads as a nod to the franchise is exactly what the originality rules exclude, and the name is also crowded, so it would be hard to protect.

### RL-012 Repo and folder name: Breakers-Like / Breakerslike
- **Searched:** Dragon Ball: The Breakers (publisher pages and Steam); "Breakerslike" and "Breakers-like"; Steam store search for "breakers"; GitHub repository search.
- **Found:** Dragon Ball: The Breakers is a live Bandai Namco game (developed by Dimps, released 14 October 2022 on PC through Steam, PlayStation 4, Xbox One, Xbox Series X|S and Nintendo Switch), in the franchise this project is a homage to. "-like" is how genres are named after a game ("roguelike"), so "Breakers-like" reads as "a game like The Breakers". Breakers is also a common word: Steam shows 501 results, including a game titled Breakers, and there is a 1996 Neo Geo fighting game called Breakers. No public GitHub repository named breakerslike turned up (private repos cannot be seen).
- **Rating:** Medium. Low while the repo is private.
- **Recommendation:** Fine while private. Before the repo goes public, rename it (GitHub redirects the old address) to the final game name or a neutral slug, and keep "Breakers" out of the public name, description, topics and README. The local folder name is not public, so leave it. When renaming, update `docs/setup/git-and-github.md`.

## Limits

- The search tool is US-only. Some sites blocked automated fetching (Justia, IndieDB), so they were not used. The itch.io search page is not reliable from here.
- Only the USPTO register was searched, and only for VORR and KAI. Not checked: the EU, UK, Japan and WIPO registers, and the USPTO for the other names (including MERIDIAN, where thousands of records are expected).
- Domain and handle checks were run only for vorr.com. Social handles were not checked.
- Results are a snapshot of 2026-09-28. Re-screen a name before it is locked or announced.
- The Lemming Ball Z listings were read through search results only, because the pages themselves blocked automated fetching. Authorship and licence terms of the fan games are not verified.
