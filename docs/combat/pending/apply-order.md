## 3. New keys for Tools

**`combat-recipes.schema.json`** (parked in `docs/tools/pending/apply-recipes.cjs`):
- The fighter key `rival` replaces `antihero`. One self-test case names the old pointer: `pool-not-for-fighter` expects `/pools/antihero`.

**`combat-finishers.schema.json`** (step 4; the rows already pass):
- Nothing in the schema. Beat args are open, so `volley` (on a cue), `gait` and `path` (on `finRush`), `slot` (on `strike` and `finalBlow`), `limb` and `shape` (on `finalBlow`) pass today. - A row's `fighter` and the keys of `select.byFighter` should be checked against `data/fighters/roster.json` once the split lands (today nothing checks them: the stand-ins `PROTAGONIST` and `RIVAL` pass).

**`combat-brawl.schema.json` and `combat-agency.schema.json`** (step 5, new files `combat.brawl/1` and `combat.agency/1`):
